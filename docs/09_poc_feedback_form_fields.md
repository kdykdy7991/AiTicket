# POC 问题反馈表字段整理

> 来源：`POC问题反馈表(1).docx`。本文用于说明 POC 问题处理过程中需要收集、填写和确认的信息。

> 流程步骤编号与 `08_poc_quality_issue_process.md` 一致（2026-09-12 起：「确认 POC 问题」「问题流转」
> 合并为「02 确认问题并流转分系统」，原「03-2 分系统接收问题」环节取消，后续阶段编号顺延）。

## 一、表单结构

表单由问题基础信息、售前现象描述、研发分析、整改措施、联合验证及四方签字确认组成。

## 二、字段清单

### 1. 问题基础信息

| 字段 | 填写内容／选项 | 说明 |
| --- | --- | --- |
| 问题名称 | 文本 | 简明描述问题主题 |
| 问题 ID | 编号 | 问题的唯一标识 |
| 产品线 | 文本或选项 | 问题所属产品线 |
| 客户名称 | 文本 | POC 对应客户名称 |
| 创建日期 | 日期 | 问题记录创建日期 |
| 问题级别 | P0 阻断、P1 严重、P2 一般、P3 低 | 单选问题严重程度 |
| 提出人 | 人员 | 问题提出人 |
| 提出部门 | 部门 | 提出人所属部门 |
| 问题类型 | 文本或选项 | 原表未给出固定选项 |
| 闭环要求 | 文本 | 闭环时限或其他闭环要求 |

### 2. 问题现象概述

- **填写责任方：** 售前

| 字段 | 填写要求 |
| --- | --- |
| 发生时间 | 问题实际发生时间 |
| 地点（经纬度） | 问题发生地点及经纬度 |
| 设备信息 | 相关设备名称、型号、编号、版本或配置等 |
| 概述 | 问题现象、触发条件、影响及复现信息 |
| 现场照片 | 能够反映现场环境或问题现象的照片 |

### 3. 研发排查与原因分析

- **填写责任方：** 研发侧（对应分系统）

| 字段 | 填写要求 |
| --- | --- |
| 初步排查结论 | 初步定位结果、已排除因素及后续排查方向 |
| 根本原因分析 | 最终定位的根因及分析依据 |

### 4. 采取措施及落实情况

- **填写责任方：** 研发侧（对应分系统）

| 字段 | 是否必填 | 填写要求 |
| --- | --- | --- |
| 临时处置措施 | 原表未标注 | 止损、规避或恢复业务的临时措施 |
| 长期整改措施 | 是 | 消除根因的长期解决方案及落实内容 |
| 计划完成时间 | 是 | 长期整改措施的计划完成日期／时间 |

### 5. 验证结果

- **确认责任方：** 售前与质量共同确认

| 字段 | 是否必填 | 填写内容／选项 |
| --- | --- | --- |
| 问题状态 | 原表未标注 | 已解决、临时解决、待复现、未解决（单选） |
| 结论 | 是 | 验证过程、结果、证据及是否认可闭环 |

### 6. 签字／确认

| 签字栏 | 对应角色 |
| --- | --- |
| 售前 | 问题提出及现场验证责任方 |
| 研发 | 问题分析及整改责任方 |
| 质量 | 质量跟踪及评审责任方 |
| 批准 | 最终批准人 |

## 三、字段与流程步骤的对应关系

| 流程步骤 | 表单填写／维护内容 | 责任方 |
| --- | --- | --- |
| 01-1 发现并提交问题 | 基础信息、问题现象概述、现场照片、闭环要求 | 售前 |
| 02-1 确认问题描述并确定分系统 | 检查问题描述及相关要素是否准确、完整；根据产品线、问题类型、设备信息和问题现象确定涉及分系统，并选定分系统负责人（确认与流转一次完成） | 专项小组 |
| 03-1 制定闭环计划 | 临时处置措施、长期整改措施、计划完成时间 | 分系统／研发侧 |
| 03-2 参与闭环计划确认 | 确认闭环要求、措施及计划时间 | 售前 |
| 04-1 实施问题分析验证 | 初步排查结论、根本原因分析、措施落实情况 | 分系统／研发侧 |
| 05-1 组织评审与确认 | 问题状态、验证结论及各方确认 | 售前、研发、质量、批准人 |
| 06-1 纳入缺陷库 | 使用已确认的反馈表信息形成缺陷库记录 | 质量 |

> 原「03-2 分系统接收问题」（确认研发责任方并开始维护排查信息）已并入 02-1：分系统负责人由专项
> 小组在流转时选定，问题流转到位后由该负责人直接维护排查信息并制定闭环计划，不再单独确认接收。

## 五、原表未明确、后续需要确认的规则

- 问题 ID 的生成规则，以及由系统生成还是人工填写。
- 产品线和问题类型是否使用固定选项。
- 各问题级别对应的响应时限和闭环时限。
- “批准”角色的具体人员或岗位，以及批准发生在哪个流程节点。
- 除现场照片外，是否还需要日志、录屏、测试报告等附件。
- “临时解决”和“待复现”状态能否进入最终闭环。
- 四方确认顺序及退回规则。
