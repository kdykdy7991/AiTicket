# 解决时限规则

## 适用范围与档位

解决时限按工单的一级分类匹配。业务保障使用 P1～P4 四档；投诉使用二级分类所确定的一般、重要、重大三档；其他需要时限的一级分类各使用一个“单档”。线索工单与即时办结工单不适用 SLA，不生成截止时间，也不计入超时率。没有配置对应档位时不生成截止时间，管理员须在“SLA 策略”页补齐配置。

## 每轮计时

- 正式建单（草稿则为正式提交）开启第一轮；部门间分诊、转派、暂缓和恢复均不重置起点。暂缓继续计时。
- 处理链最后一步提交结果、工单进入客服闭环节点时结束本轮。业财对账销售到财务的转交以及业务保障的中间处理节点不属于终点。
- 客服收到结果后退回重办，从退回动作开始下一轮；之前各轮的起点、截止时间、终点和超时结果保留。客服持有结果到退回之间不计入新一轮。
- 工单撤销会终止运行中的轮次，标记为撤销而非已解决；撤销工单不计入超时率。
- 策略修改只影响之后开启的轮次。运行中轮次的时长在建单或退回时确定；工单分类或优先级被更正时，按同一轮原起点重新计算截止时间。

历史策略按旧“部门＋优先级”口径留存在 `sla_policies_legacy`。迁移会将可直接转换的全局时限转成分类档位；原部门专属覆盖因新规则不再按部门匹配，保留供人工核对。投诉升级路由仍独立存在，不再用倍率计算时限。
