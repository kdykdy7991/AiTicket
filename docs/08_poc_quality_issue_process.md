# POC 质量问题闭环流程（文字版）

> 本文根据 POC 问题处理流程图整理，用于记录当前流程基线，便于后续进行 POC 专项流程调整。

## 一、流程概览

POC 质量问题从发现到纳入缺陷库，共分为 7 个阶段：

1. 发现 POC 问题
2. 确认 POC 问题
3. 问题流转
4. 确认闭环计划
5. POC 问题推进
6. 质量评审／确认
7. 纳入缺陷库

流程涉及 4 类角色或责任主体：

- 售前
- 专项小组
- 分系统
- 质量

## 二、详细流程

### 01 发现 POC 问题

#### 01-1 发现并提交问题

- **责任方：** 售前（售前与解决方案部）
- **操作入口：** 工单系统
- **主要动作：** 发现质量问题，提交问题，并提出闭环周期要求。
- **提交信息／产出物：** 问题描述及相关要素信息。
- **后续审批：** 提交后由邱总审批；审批通过后流转至专项小组确认。

### 02 确认 POC 问题

#### 02-1 确认问题描述

- **责任方：** 专项小组
- **确认人：** Allen（陈毅君）
- **主要动作：** 确认质量问题描述的准确性。
- **流转结果：** 确认后进入问题涉及范围识别及流转环节。

### 03 问题流转

#### 03-1 确定涉及的分系统

- **责任方：** 专项小组
- **主要动作：** 初步确定问题涉及的分系统，并将问题流转至对应分系统。
- **涉及系统及人员：**

  1. 系统总体：邓雪群
  2. 卫星平台：卢翔
  3. 终端系统：余华伟
  4. 应用平台：邱庆举
  5. 测运控平台：倪汉华

#### 03-2 分系统接收问题

- **责任方：** 对应分系统
- **主要动作：** 确认接收质量问题。
- **流转结果：** 接收后进入质量问题闭环计划制定环节。

### 04 确认闭环计划

#### 04-1 制定闭环计划

- **责任方：** 对应分系统
- **操作入口：** 工单系统
- **主要动作：** 确定质量问题闭环计划。
- **产出物：** 质量问题闭环计划。

#### 04-2 参与闭环计划确认

- **责任方：** 售前
- **主要动作：** 参与质量问题闭环计划确认。
- **流转结果：** 闭环计划确认后，进入问题分析和验证阶段。

### 05 POC 问题推进

#### 05-1 实施问题分析验证

- **责任方：** 对应分系统
- **操作入口：** 工单系统
- **主要动作：** 按闭环计划实施质量问题分析和验证。
- **产出物：** 质量问题分析报告。
- **过程跟踪：** 质量人员主导质量问题追踪，并维护质量问题跟踪表。

### 06 质量评审／确认

#### 06-1 组织评审与确认

- **责任方：** 质量
- **参与人：** 金凯、马祥艺、巫雪峰
- **操作入口：** 工单系统
- **主要动作：** 基于问题分析和验证结果，组织质量问题评审／确认。
- **输入／过程材料：** 质量问题分析报告、质量问题跟踪表。
- **产出物：** 评审／确认结果。
- **流转结果：** 评审确认后，将质量问题转入缺陷库。

### 07 纳入缺陷库

#### 07-1 录入缺陷库

- **责任方：** 质量
- **操作入口：** SVN
- **主要动作：** 将评审确认后的质量问题纳入缺陷库。
- **流程结果：** POC 质量问题完成当前流程闭环，并进入缺陷库管理。

## 三、端到端流转关系

```text
售前发现并提交问题（工单系统）
  → 邱总审批
  → 专项小组确认问题描述准确性
  → 专项小组初步确定涉及的分系统并流转
  → 分系统确认接收问题
  → 分系统制定质量问题闭环计划（工单系统）
  → 售前参与闭环计划确认
  → 分系统实施问题分析和验证（工单系统）
  → 质量主导问题追踪并维护跟踪表
  → 质量组织问题评审／确认（工单系统）
  → 质量将问题纳入缺陷库（SVN）
```
